## 🎮 About The Game

**Le Piano** is an indie rhythm game designed around clean visual feedback, atmospheric sound design, and smooth keyboard interaction. Hit falling notes in sync with the rhythm and test your accuracy in a sleek, minimalist environment.

### ✨ Key Features
* 🎵 **Precise Rhythm Mechanics** — Responsive input handling and tight note synchronization.
* 🎨 **Atmospheric UI** — Minimalist, focused design that puts the music front and center.
* 🌐 **Browser Ready** — Playable instantly on WebGL/HTML5 without downloading.
